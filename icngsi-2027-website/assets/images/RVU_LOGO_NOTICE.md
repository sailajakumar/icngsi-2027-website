# RV University logo usage

The website header and footer use the current RV University logo assets from the official RVU website:

- Header logo: https://d2b6aloc836m7p.cloudfront.net/wp-content/uploads/2025/02/RVU-logo.svg
- Footer dark-background logo: https://d2b6aloc836m7p.cloudfront.net/wp-content/uploads/2025/03/RVU-logo-white.png

For offline deployment, download the official approved logo files from RV University/communications team and replace these URLs in all HTML pages, or replace them with local files under `assets/images/`.
