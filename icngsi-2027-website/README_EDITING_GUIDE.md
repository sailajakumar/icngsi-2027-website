# ICNGSI 2027 Website Editing Guide

This package is a fully editable static website for the International Conference on Next-Generation Computing and Sustainable Intelligence (ICNGSI 2027).

## Main files to edit

- `index.html` — home page
- `call-for-papers.html` — call for papers
- `tracks.html` — seven conference tracks
- `important-dates.html` — author timeline
- `author-guidelines.html` — author submission guidelines
- `leadership.html` — leadership and organising roles
- `technical-advisory-committee.html` — technical advisory committee
- `reviewer-committee.html` — reviewer committee
- `contact.html` — conference secretariat
